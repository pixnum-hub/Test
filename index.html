Metadata (title/thumbnail) always comes from YouTube's own free oEmbed endpoint above. Turning a link into a real file needs a separate "cobalt" processing server — YouTube actively blocks shared public ones, so the default above will often reply with an auth error. Browse cobalt.directory for one that's online right now and paste its URL here.

Self-host your own instance (most reliable)

One Docker container, no database. Save as docker-compose.yml and run docker compose up -d:

services:
  cobalt-api:
    image: ghcr.io/imputnet/cobalt:11
    container_name: cobalt-api
    init: true
    restart: unless-stopped
    ports:
      - 9000:9000/tcp
    environment:
      API_URL: "https://your-domain-or-tunnel/"

Then set the instance URL above to that address. YouTube may still need a disposable Google account's cookies file for reliable access — see the project's GitHub docs for the cookies setup, or deploy a hosted copy in one click via Railway.
